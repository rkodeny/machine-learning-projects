# Machine Learning Projects

## Overview

This repository contains a collection of **basic to intermediate machine learning projects** covering data analysis, machine learning, deep learning, NLP, computer vision, anomaly detection, and time-series forecasting.

Each project is provided as a **standalone Jupyter Notebook**, so it can be cloned and executed independently with minimal setup.

---

## What You Will Learn

* **Data Cleaning & Preprocessing** – handling missing values, encoding, scaling, and preparing real-world data
* **Exploratory Data Analysis (EDA)** – visualization, statistical analysis, and feature understanding
* **Machine Learning** – classification, regression, and anomaly detection techniques
* **Deep Learning** – CNNs, transfer learning, and NLP models
* **Computer Vision** – image analysis, detection, recognition, and pose estimation
* **Time-Series Forecasting** – feature engineering, seasonal analysis, and forecasting models

* Python **3.9+**
* Jupyter Notebook or **Google Colab**

## Installation

Clone the repository:

```bash
git clone https://github.com/rkodeny/machine-learning-projects.git
cd machine-learning-projects
```

Run any project:

```bash
cd "Weather Forecasting"
pip install -r requirements.txt
jupyter notebook
```
